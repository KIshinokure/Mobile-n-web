# Mobile-n-web

Лабораторные работы по мобильным и веб-технологиям (вариант 5).

| Папка | Работа | Отчёт |
|---|---|---|
| [lab2](lab2) | Работа с базой данных и серверной частью: новости со счётчиком «Like» (PHP + MySQL + AJAX), маршруты Laravel и Yii2 | [Отчет_ЛР2.docx](lab2/Отчет_ЛР2.docx) |
| [lab3](lab3) | Разработка и тестирование веб-форм | [Отчет_ЛР3.docx](lab3/Отчет_ЛР3.docx) |
| [lab4](lab4) | Интерфейс СУБД MySQL, привилегии, утилиты mysqladmin / mysqlshow / mysqldump | [Отчет_ЛР4.docx](lab4/Отчет_ЛР4.docx) |
| [lab5](lab5) | Элементы работы с формами (Java Swing, NetBeans) | [Отчет_ЛР5.docx](lab5/Отчет_ЛР5.docx) |
| [lab6](lab6) | Использование Cookies (Apache SSI) | [Отчет_ЛР6.docx](lab6/Отчет_ЛР6.docx) |
| [lab7](lab7) | Сессии, события и фильтры (JSP / Servlet, Tomcat) | [Отчет_ЛР7.docx](lab7/Отчет_ЛР7.docx) |

В каждой папке лежат отчёт `.docx` и рядом с ним все файлы кода, готовые для копирования и запуска (`.html`, `.php`, `.sql`, `.java`, `.jsp`, `.shtml` и т.д.). Скриншоты — в `screenshots/`, журналы запуска — в `logs/`, дампы ЛР 4 — в `lab4/dumps/`. В ЛР 2 проекты на фреймворках лежат в подпапках `laravel/` и `yii2/`: их файлы копируются с сохранением путей поверх свежего проекта Laravel / Yii2.
